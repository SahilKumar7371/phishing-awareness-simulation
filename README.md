# 🛡️ PhishGuard – Phishing Awareness Simulation

An interactive cybersecurity awareness project designed to educate users about phishing attacks through safe and realistic simulations. The project demonstrates how attackers use social engineering techniques and helps users learn how to identify and avoid phishing attempts. The application is completely client-side, requires no backend, and does not collect any user data.

## 📌 Project Overview

PhishGuard is an educational web-based simulation that allows users to experience common phishing attacks in a controlled and safe environment. The project focuses on awareness and training rather than actual attack execution. It includes realistic scenarios, instant feedback, awareness training, and a knowledge quiz.

### Simulated Attack Types

* 📧 Email Phishing
* 📱 Smishing (SMS Phishing)
* 📷 Quishing (QR Code Phishing)

These simulations help users recognize warning signs and understand how cybercriminals manipulate victims through social engineering techniques.

## 🏗️ System Workflow

1. Home Screen
2. Consent Form
3. Technique Selection
4. Phishing Simulation
5. Fake Login/OTP Page
6. Results & Warning Signs
7. Awareness Training
8. Quiz Assessment
9. Dashboard & Statistics

This workflow helps users understand phishing attacks from start to finish in a safe learning environment.

---

## 🔒 Security & Privacy

PhishGuard follows a strict privacy-first design:

* No credentials are stored.
* No personal data is collected.
* No database is used.
* No backend server exists.
* Session data is temporary.
* All entered information is discarded immediately.
